# Contract Risk Analysis System

AI-powered contract risk analysis using ML and agentic AI.

## Features

- ML-based risk classification
- Agentic AI risk analysis with legal guidelines
- PDF and TXT contract support
- Interactive web interface

## Quick Start

### Backend
```bash
cd backend
pip install -r requirements.txt
export GEMINI_API_KEY=your_key
python3 main.py
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```

Access at http://localhost:5173

## Tech Stack

- Backend: Python, FastAPI, scikit-learn, ChromaDB
- Frontend: React, TypeScript, Vite
- AI: Google Gemini API
